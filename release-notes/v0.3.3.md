# StreamDek TV v0.3.3

## What's New

- **Next Episode now follows the episode's real ending.** IntroDB, TheIntroDB or StreamDek's
  internal fallback decides when the unified End-of-Play card appears. When autoplay is enabled,
  its countdown is calculated from the current episode's remaining playable time, including a
  detected intended endpoint where appropriate. Selecting **Next Episode** overrides the countdown
  and starts the transition immediately.

- **Unaired episodes are handled honestly.** StreamDek now separates release metadata from source
  availability. A future episode shows no countdown and starts no background source search. Its
  card offers **Skip Ending**, which completes the current episode without trying to play the
  unaired one. Recommendations can appear inside that same card without opening a competing panel.
  Missing or malformed dates fail safely as unknown, while an aired episode with no stream is still
  recognised as aired.

## Improvements

- **Faster next-episode handoff.** Playable sources are prepared progressively behind the card,
  independently of its presentation and countdown. If a source is not ready at zero, the existing
  card moves into loading and begins as soon as preparation completes.
- **New Episodes excludes completed episodes.** Provider watched history and the latest SyncDek
  playback state now keep watched episodes out of the row, while an explicit newer unwatched state
  is respected.
- **KinoCheck-first trailers.** KinoCheck receives a bounded first opportunity before StreamDek
  falls back to metadata and its existing YouTube route.
- **Smoother profile entry.** The startup profile picker establishes focus before its reveal,
  removing the late focus flash as cards animate onto the screen.

## Fixed

- Fixed the End-of-Play card waiting for source discovery before presenting its decision.
- Fixed autoplay countdowns using a fixed timer instead of the time remaining in the current
  episode.
- Fixed manual Next Episode selection waiting for the current episode to finish.
- Fixed normal seek buffering being reported as a stalled stream.
- Fixed Back navigation occasionally leaving the permanent TV shell around an empty or black Home
  screen; malformed navigation stacks now recover to a fresh Home entry.
- Fixed duplicate next-episode and recommendation surfaces appearing at the same ending.
