# StreamDek TV v0.2.7

## What's New

- **Hide card titles** on the Home screen, under **Settings → Home & Layout**. A poster usually
  carries its own title in the artwork, so the overlay repeats in worse type what the picture
  already says and covers the bottom third of it doing so. Off by default, and offered only when
  Home row cards are set to Portrait — a landscape still is often unidentifiable without its
  title, so those rows keep it. Live and Continue Watching cards keep theirs too: the same block
  holds the channel name, the episode and the progress bar.

## Improvements

- **Audio and subtitle tracks are named rather than coded.** The pickers listed "ENG", "FRE",
  "PT-BR" — whatever tag the file happened to carry. They now read English, French, Portuguese,
  and add-on subtitle results are named the same way. A tag StreamDek does not recognise is left
  exactly as it was written rather than being called "Unknown".

- **Update notes are rendered.** Release notes are written as Markdown and were shown as their own
  punctuation — hashes in front of every heading, hyphens in front of every bullet, nothing
  separating one section from the next. Headings, lists, emphasis and links now render properly in
  the update prompt and on the Account panel, and the notes card is taller to suit.

- **Quality, size and availability show on every stream row.** Those columns were tied to StreamDek
  Formatting, which is off by default, so a result showed "FebBox · 4K" in the picker and
  "FebBox · 4K | 4K | 5.01 GB" a second later on the loading screen — it had the size all along.
  The columns are read from what the add-on already sent, so they now appear in both modes; the
  add-on's own text is still never rewritten.

- **Stream rows no longer print the same line twice.** Several sources fill both of their text
  fields with the same string, and both were shown, so those results took two lines to say one
  thing. The second line now appears only when it has something the first did not — in the picker
  and in the source list inside the player.
