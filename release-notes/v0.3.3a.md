# StreamDek TV v0.3.3a

## Improvements

- **Clearer next-episode feedback.** The End-of-Play card now keeps one Cancel action and changes
  **Next Episode** to **Preparing…** while StreamDek finds a playable source, so a remote press is
  visibly acknowledged without duplicating controls.

- **Localized End-of-Play guidance.** Next-episode availability, autoplay, recommendation and
  action text now follows the selected TV interface language across German, Spanish, French,
  Italian, Dutch, Polish and Portuguese.

## Fixed

- **Next Episode presses appearing to do nothing.** Playback-position updates could cancel the
  card's background source search while leaving it marked as active, preventing the button from
  starting another lookup. Source discovery now survives those updates and always clears its
  loading state when it ends.

- **Autoplay stopping at the end of an episode.** Reaching the countdown endpoint or the actual
  end of the file now either starts an already prepared next episode or guarantees a fresh source
  lookup. A queued transition can no longer fall into an idle no-op while the End-of-Play card is
  visible.

- **Linux release checks unable to start Gradle.** The Gradle wrapper now retains its executable
  permission in Git so Ubuntu-based validation workflows can run normally.
