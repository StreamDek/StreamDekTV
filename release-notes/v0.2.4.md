# StreamDek TV v0.2.4

## What's New

- Trailers that YouTube's player API refuses now play through YouTube's own embed instead of silently doing nothing. This covers the "Sign in to confirm you're not a bot" wall, which YouTube applies to whole networks at a time and which no sign-in can answer, as well as age-gated trailers that native extraction has never been able to reach. The embed is not interactive: the remote still belongs to the trailer stage, OK pauses and Back exits.
- New Trailer start delay setting, from Immediately to 5 seconds, controlling how long a title page is left alone before its trailer begins. The default is now 3 seconds rather than 4. It is the same synced value used by StreamDek Mobile and the web portal, so choosing it once settles it on every device. The trailer button ignores the delay and plays straight away.

## Improvements

- The trailer action now reads Trailer unavailable when neither route produced a playable trailer, instead of leaving a press with no visible result. The next press tries again.
- A resolved trailer that fails as it starts is retried once through the embed before the page returns. These playback links are short-lived and single-use, so one that was valid when it was resolved can be refused a moment later.
- Back is no longer swallowed while focus is parked on a collapsed navigation rail during a screen transition. It leaves the screen, which is what was meant by it.
- Returning from the player to the stream list restores the exact list that was open, taken from the snapshot the player was entered with, rather than starting a second lookup that could come back briefly or permanently empty.
- Trailer resolution no longer carries the unused signed-in cookie path. The television resolves anonymously only.

## Fixes

- Fixed the navigation rail flashing open on every Back press and collapsing again once content arrived. Expansion now waits on the arriving screen having held focus rather than on a fixed timer, so a screen slower than that timer no longer plays the whole expansion. Pressing left into the rail still opens it immediately, and a rail that has been focused still opens on any press, so it cannot be left unreachable on a screen with nothing focusable.
- Fixed a trailer resolve that was cancelled by leaving the page being treated as a refusal by YouTube, which could raise a trailer over a screen the viewer had already left.
