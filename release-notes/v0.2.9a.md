# StreamDek TV v0.2.9a

## Fixed

- **Continue Watching now updates properly after watching on the TV.** Progress that had already
  synchronized to mobile could remain missing from the TV Home screen because Home retained an
  older library snapshot. Home now refreshes after TV progress and watched changes, whenever it
  is reopened, and periodically while it remains visible.

- **Marking an episode watched removes stale Continue Watching cards.** The TV now invalidates
  its Home and library state as soon as the watched update succeeds, instead of continuing to
  display the completed episode from an earlier snapshot.

- **Continue Watching no longer remains on an endless loading screen.** The exact episode and
  resume position are preserved while the TV checks its remembered source. If that source is
  missing, expired or unavailable, StreamDek explains what happened and automatically searches
  for a fresh source.

- **Failed automatic recovery leads somewhere useful.** Source searches now have a bounded
  timeout. If no playable replacement can be found, **Choose a Source** opens the source picker
  for the same episode so another source can be selected manually.

## Improvements

- **Remember Last Source now has a clear TV fallback.** The television reuses its own remembered
  source when possible, but resolves playback links locally because temporary URLs and
  device-specific provider credentials are not safe to reuse across devices.
