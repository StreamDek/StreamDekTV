# StreamDek TV v0.1.3

## What's New

- Added a full Live TV channel browser with addon and catalog filters, channel search, favourites, and fast channel switching from the player.
- Added Media3 playback alongside MPV, including an automatic MPV fallback when a source cannot play through the default engine.
- Added playback-engine selection and remembered-source behavior that follows your synced playback preferences.

## Improvements

- Live streams now recover more reliably from stalls and provider interruptions by reloading or refreshing the source before showing an error.
- Improved HLS, DASH, MKV, MP4, and WebM playback with request-header support, decoder fallback, better buffering, and audio/subtitle track selection.
- Refined TV remote navigation, long-press actions, stream selection, player controls, seeking, and return navigation across Home, Search, Library, Details, and Live TV.
- Live playback now includes clearer channel information, favourites access, and smoother switching between channels from the same addon.

## Fixes

- Fixed playback failures and black-screen cases affecting some direct, bridged, and live sources.
- Fixed repeated live-stream failures by bounding automatic retries and exposing a manual retry when the provider remains unavailable.
- Fixed remembered stream selection so it is used only when the corresponding preference is enabled.
- Fixed several player focus, overlay, progress, and exit-state inconsistencies on TV remotes.
