# StreamDek TV v0.0.8

## What's New

- Added Trakt playback scrobbling from the TV player so progress updates stay aligned with mobile.
- Added in-app update packaging support with a matching release manifest and TV-facing release notes.
- Added TV interface options for theme selection, start screen selection, and home row display style.
- Added smoother anchored row scrolling across home, search, library, streams, and detail rails.

## Improvements

- Player exits now return to the streams list instead of dropping back unpredictably.
- Stream resolution timeouts are handled more safely instead of crashing the app.
- Media detail buttons now use the active theme color for the focus highlight.
- Floating-nav down navigation now lands on the first content card more reliably.
- Watchlist behavior remains Trakt-backed for sync consistency with mobile.

## Fixes

- Fixed multiple Compose focus-request crashes in the player.
- Fixed a media-details crash caused by invalid focus handoff while scrolling.
- Removed subtitle language and audio language rows from TV settings.
- Improved focus behavior when entering comments, cast, and similar-title sections.
