# StreamDek TV v0.1.8

## What's New

- Rebuilt Settings for TV with remote-friendly controls, themed dropdown menus, instant toggles, and clearer provider and plugin management.
- Expanded the player with improved Live and VOD handling, progress controls, source selection, audio and subtitle options, playback speed, and clearer status badges.
- Added season-level watched controls and episode context menus so individual episodes can be marked as watched directly from Media Details.
- Added collapsible navigation and control sidebars that create more room for content while remaining easy to reach with the remote.

## Improvements

- Home navigation is significantly smoother, with GPU-accelerated row transitions, consistent card spacing, and cleaner movement between shelves.
- Hero artwork, title logos, and copy now transition smoothly as focus changes. Title logos are prefetched and cached for faster display, and synopsis text has more room.
- Refreshed Home, Search, Library, Live TV, Media Details, and Settings layouts for more consistent cards, focus treatment, spacing, and typography.
- Media Details now provides smoother card focus animations, better minified rows, improved action buttons, and resume progress directly in the main play button.
- Plugin sources are grouped beneath collapsible parent plugins, with separate sections for regular plugins, CloudStream, and SkyStream sources.
- Stream selection now better respects remembered sources, preferred providers, quality, language, direct-play availability, and the hidden stream-picker preference.
- Player timeline focus is retained while scrubbing, with a compact on-screen hint for remote controls.

## Fixes

- Fixed several D-pad navigation crashes in Settings and the player.
- Fixed focus getting trapped between Settings columns, unexpectedly jumping to navigation, or opening the search keyboard without an explicit click.
- Fixed Home rows bleeding into one another, clipping on the right, stretching during row changes, or appearing excessively spaced during initial loading.
- Fixed Media Details action buttons incorrectly opening the streams page and corrected clipped Cast, episode, and More Like This rows.
- Fixed stream discovery restarting after multiple providers had already returned results and dropping previously loaded sources.
- Fixed disabled built-in add-ons, synced provider lists, and installed plugins not being represented correctly in Settings.
- Fixed metadata resolution failures affecting some add-on catalogue titles.
- Removed the redundant Continue Watching card badge and the player's 10-second rewind menu action.
