# StreamDek TV v0.0.9

## What's New

- Reworked the in-app update prompt into a centered modal dialog that sits above the rest of the TV UI.
- Added a dedicated `What's New` panel inside the update prompt with focusable TV navigation.
- Added a themed scrollbar to the `What's New` panel so long update notes are visibly scrollable.

## Improvements

- Update prompt focus is now confined to the popup instead of leaking to the home screen behind it.
- The floating navigation is hidden while the update prompt is open so the modal remains the top interaction layer.
- The `What's New` panel now opens focused when release notes are present.
- Update prompt button layout has more room because the redundant version-ready line was removed.

## Fixes

- Fixed TV DPAD scrolling inside the `What's New` panel.
- Fixed update prompt layering so it appears above the floating nav and page content.
- Fixed visual focus treatment for the `What's New` panel so the active region is clearly highlighted.
