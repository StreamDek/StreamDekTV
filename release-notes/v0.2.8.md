# StreamDek TV v0.2.8

## Fixed

- **Add-on subtitles that never appeared.** Choosing a subtitle could leave the row looking
  selected, nothing on screen, and no explanation of which of the two had gone wrong. Four
  independent things caused it, and all four are fixed:

  - **The format was guessed from the address.** These addresses carry no extension —
    `.../file/1962235234` — and the host's content type is whatever it felt like sending, so a
    WebVTT or ASS subtitle was saved as SubRip and parsed to nothing at all. The format is now
    read from the file itself.

  - **The text was assumed to be UTF-8.** OpenSubtitles serves CP1252 for plenty of titles, and
    read as UTF-8 every accented character was lost. The encoding is now detected — real UTF-8
    either decodes or fails, which is a reliable signal rather than a guess — and everything is
    rewritten as UTF-8 so the players only ever see one encoding.

  - **Downloads did not look like a browser.** Several of the hosts these add-ons point at refuse
    anything that does not, and a refusal arrives as a subtitle that simply never shows up.

  - **A subtitle whose link had expired just failed.** These links expire routinely, so the next
    copy in the same language is now tried first — up to four of them — exactly as a failed
    stream falls through to the next source. Only when none of them load are you told, and the
    message says that rather than blaming the one you picked.

## Improvements

- **Subtitle lookups report what each source returned.** A source that could not be reached, one
  that answered with an error, and one that simply had nothing for this title all produced the
  same silent absence from the list before. Each now records what it returned and how much of it
  was usable, so a source that looks missing can be told apart from one that is genuinely empty.
