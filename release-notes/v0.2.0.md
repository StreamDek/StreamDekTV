# StreamDek TV v0.2.0

## What's New

- Plugin sources now run on the TV. Sources installed from StreamDek Mobile or the control centre answer stream requests here too, arriving in the source list alongside add-on results with a tab of their own. Only the configuration travels through your account, so the TV fetches each source's scraper itself and keeps it cached between sessions.
- Usenet sources now play. StreamDek fetches the NZB, pulls the articles from the news server the source names, and decodes and reassembles them here on the TV. Playback starts on the first part rather than waiting for the whole file, and seeking moves the download ahead instead of working through everything in between. All of it happens on this TV — no part of a usenet stream is routed through a StreamDek server. Posts that need par2 repair or arrive packed in RAR archives are not supported yet.
- Usenet results now appear in the source list instead of being left out. For some titles nearly every result is a usenet one, and hiding them made those titles look as though nothing had been found at all. They are marked Usenet in the availability column.
- Added a settings cog to plugin sources that ask for an API key or other options. The fields come from the source itself, so it asks for exactly what it needs, and anything you enter stays on this TV.

## Improvements

- The source list fills in from plugin sources as each one finishes, the way add-on results already did, so the first results appear without waiting for the slowest scraper.
- Media Details falls back to an add-on's own description when a title cannot be found on TMDB. Catalogue titles with ids TMDB does not recognise now open properly instead of reporting that details could not be loaded.
- Plugin scrapers are downloaded quietly in the background after sign-in, so the first stream search of a session does not wait on them.
- Usenet sources sit below playable ones in the list, and starting playback without choosing a source skips straight past them to something that can play immediately.

## Fixes

- Fixed the handoff prompt from StreamDek Mobile arriving with no heading. The text and buttons were there; the "Continue on this TV?" title above them was invisible against the panel.
- Fixed diagnostic entries from AIOStreams appearing in catalogue rows as cards with no artwork that lead nowhere. The add-on adds one whenever a catalogue behind it fails, and they are now left out of the row.
- Fixed titles from some add-on catalogues showing an error in place of their description, and then finding no sources. An add-on that could not describe an item is now passed over rather than believed.
- Fixed results from add-ons that had already answered disappearing from the source list as later ones finished.
